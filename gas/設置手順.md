# 投稿記録をスプレッドシートに集める（初回だけ・5分）

矢部さんの Google アカウントで、1回だけ設定します。
**作業される方の側には、何のアカウントも要りません。**

---

## 1. スプレッドシートを開く

https://docs.google.com/spreadsheets/d/1GgROCjiaK5QKzroyMtErOlnb7PllQqDAClps8GdVM80/edit

（名前は「芸能労災 投稿記録（投稿デスクから自動で入ります）」。すでに作ってあります）

## 2. スクリプトの画面を開く

上のメニューの **「拡張機能」→「Apps Script」**。新しいタブが開きます。

## 3. コードを貼り替える

最初から入っている `function myFunction() { }` を**すべて消して**、
このフォルダの **`コード.gs` の中身を全部貼り付け**ます。

貼ったら、上の **フロッピーのアイコン（保存）** を押します。

## 4. いちど実行して、権限を許可する

上の関数名の欄を **`準備`** にして、**「実行」** を押します。

- 「承認が必要です」と出たら **「権限を確認」**
- Google アカウントを選ぶ
- **「このアプリは Google で確認されていません」** と出たら、
  左下の **「詳細」→「（プロジェクト名）に移動」**
  ※ ご自分で作ったスクリプトなので、この警告で問題ありません
- **「許可」**

スプレッドシートに「投稿記録」というシートと見出し行ができていれば成功です。

## 5. デプロイする（ここがいちばん大事）

右上の **「デプロイ」→「新しいデプロイ」**。

1. 左の歯車 **「種類の選択」→「ウェブアプリ」**
2. **説明**：`投稿デスク`（何でもかまいません）
3. **次のユーザーとして実行**：**自分**
4. **アクセスできるユーザー**：**全員** ←★ここを必ず「全員」にする
5. **「デプロイ」**

## 6. URLをコピーして、私に貼ってください

デプロイ後に出る

```
https://script.google.com/macros/s/AKfycb.../exec
```

この **`/exec` で終わるURL** をコピーして、チャットに貼ってください。
サイト側につないで、公開しなおします。

---

## そのあとどうなるか

- 作業される方がサイトで「保存」を押す → **このスプレッドシートに1行増えます**
- 矢部さんはスプレッドシートを開けば、スマホでもすぐ見られます
- サイトを開いた全員の画面に、**誰がいつ何を投稿したか**が出ます
- 私がシートを読んで、`output/posting_log.md` に転記します

## 直したいとき

**コードを直したら、もう一度「デプロイ」→「デプロイを管理」→ 鉛筆 →
「バージョン」を「新バージョン」にして「デプロイ」** をしてください。
新しいデプロイを作り直すとURLが変わってしまいます。

## 知っておいていただきたいこと

**このURLは、知っている人なら誰でも書き込める入口になります。**
投稿デスクのページが公開されているため、URLも公開されます。

そのうえで、次の歯止めを入れてあります。

- **X と Instagram の投稿URLの形でないものは、1行も書き込まれません**
- **1日に入る行数に上限**があります（60行）
- 書き込めるのは**追記だけ**。既にある記録を消したり、シートの他の場所を触ったりはできません
- スプレッドシート自体は矢部さんのもので、**中身を読めるのは矢部さんだけ**です

それでも気になる場合は、GitHub の公開をやめて（リポジトリを private にして）、
Claude の共有ページに移す方法もあります。そのときは言ってください。
