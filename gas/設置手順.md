# 投稿記録をスプレッドシートに集める（初回だけ・5分）

矢部さんの Google アカウントで、1回だけ設定します。
**作業される方の側には、何のアカウントも要りません。**

---

## 1. スプレッドシートを開く

https://docs.google.com/spreadsheets/d/1GgROCjiaK5QKzroyMtErOlnb7PllQqDAClps8GdVM80/edit

（名前は「芸能労災 投稿記録（投稿デスクから自動で入ります）」。すでに作ってあります）

## 2. スクリプトの画面を開く

上のメニューの **「拡張機能」→「Apps Script」**。新しいタブが開きます。

※ すでに https://script.google.com/... のタブを開いてある場合は、そのまま使って構いません。
書き込み先はスクリプトの中でIDで指定しているので、どちらから開いても同じように動きます。

## 3. コードを貼り替える

**いちばん多い失敗：元の `function myFunction() { }` が残ったまま、その中に貼ってしまう。**
そうなると関数として認識されず、次の手順で関数を選べません。

1. エディタの中を1回クリックする
2. **Ctrl + A**（全部選ぶ）→ **Delete**（空っぽにする）
3. **1行目が空の状態**を確認してから、`コード.gs` の中身を全部貼り付ける
4. **Ctrl + S**（保存）。上の「変更が保存されていません」が消えます

**貼り終わったとき、1行目は `/**` で始まっています。**
`function myFunction()` がどこかに残っていたら、消してもう一度保存してください。

## 4. いちど実行して、権限を許可する

**保存しないと関数の選択欄は空のままです。** 先に保存してください。

ツールバーの **「デバッグ」の右どなり**（「関数なし」と出ている欄）を押して、
**`準備`** を選び、**「実行」** を押します。

- 「承認が必要です」と出たら **「権限を確認」**
- Google アカウントを選ぶ
- **「このアプリは Google で確認されていません」** と出たら、
  左下の **「詳細」→「（プロジェクト名）に移動」**
  ※ ご自分で作ったスクリプトなので、この警告で問題ありません
- **「許可」**

スプレッドシートに「投稿記録」というシートと見出し行ができていれば成功です。
（スクリプトは**シートのIDで**書き込み先を指しているので、
この Apps Script をスプレッドシートから開いていなくても動きます）

## 5. デプロイする（ここがいちばん大事）

右上の **「デプロイ」→「新しいデプロイ」**。

1. 左の歯車 **「種類の選択」→「ウェブアプリ」**
2. **説明**：`投稿デスク`（何でもかまいません）
3. **次のユーザーとして実行**：**自分**
4. **アクセスできるユーザー**：**全員** ←★ここを必ず「全員」にする
5. **「デプロイ」**

## 6. URLをコピーして、私に貼ってください

デプロイ後に出る

```
https://script.google.com/macros/s/AKfycb.../exec
```

この **`/exec` で終わるURL** をコピーして、チャットに貼ってください。
サイト側につないで、公開しなおします。

## そのあとどうなるか

- 作業される方がサイトで「保存」を押す → **このスプレッドシートに1行増えます**
- 矢部さんはスプレッドシートを開けば、スマホでもすぐ見られます
- サイトを開いた全員の画面に、**誰がいつ何を投稿したか**が出ます
- 私がシートを読んで、`output/posting_log.md` に転記します

## コードを直したとき（URLを変えずに入れ替える）

**「新しいデプロイ」をもう一度やるとURLが変わってしまいます。** かならずこの手順で。

1. エディタで **Ctrl + A → Delete**、新しい `コード.gs` を貼って **Ctrl + S**
2. 右上の **「デプロイ」→「デプロイを管理」**
3. 右上の **鉛筆（編集）** をクリック
4. **「バージョン」を「新バージョン」** に変える
5. **「デプロイ」**

**承認のやり直しは要りません。** URLもそのままです。

## 知っておいていただきたいこと

**このURLは、知っている人なら誰でも書き込める入口になります。**
投稿デスクのページが公開されているため、URLも公開されます。

そのうえで、次の歯止めを入れてあります。

- **X と Instagram の投稿URLの形でないものは、1行も書き込まれません**
- **1日に入る行数に上限**があります（60行）
- 書き込めるのは**追記だけ**。既にある記録を消したり、シートの他の場所を触ったりはできません
- スプレッドシート自体は矢部さんのもので、**中身を読めるのは矢部さんだけ**です

それでも気になる場合は、GitHub の公開をやめて（リポジトリを private にして）、
Claude の共有ページに移す方法もあります。そのときは言ってください。
